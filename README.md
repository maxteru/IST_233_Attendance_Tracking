Модуль учёта посещения занятий

Инструкция по запуску:

1. Скачать Visual Studio Community
2. Выбрать все необходимые рабочие нагрузки - разработка веб и классических приложений на C#
3. Установить Microsoft SQL Server Management Studio 20
4. Имя сервера должно быть таким - (LocalDB)\MSSQLLocalDB
5. Запустить проект через Visual Studio 2022/
6. Удалить папку миграций - Migrations. Перейти в Вид - Другие окна - Консоль диспетчера пакетов и написать команды: Add-Migration Initial и Update-Database. 
7. Запустить проект, добавлять/удалять/редактировать студентов и тд.
